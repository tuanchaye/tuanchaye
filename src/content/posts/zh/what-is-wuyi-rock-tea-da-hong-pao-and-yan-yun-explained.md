武夷岩茶是产自福建北部武夷山峡谷中的焙火乌龙茶。这个名字并非指单一茶品。中国国家标准在其下定义了五种产品类型——大红袍、名丛、肉桂、水仙和奇种——它们都具有业界称为“岩韵”的品质。

有两件事会让买家感到意外。大红袍，这个类别中最著名的名字，在法律上是一种**拼配茶**，而非来自单一古老茶树的茶叶。而茶叶来自哪个具体峡谷，可能使其价格相差一个数量级，其原因只有部分是化学性的。

## 五种法定类型

GB/T 18745 根据每种类型的原料来定义它们，这使得该类别比营销宣传所暗示的更容易理解。

表格

| 类型        | 法定定义                                                                                | 实际情况                                                                                     |
| ----------- | ----------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| 大红袍 | 由多个无性繁殖的武夷品种的半成品原料，经拼配匀堆制成 | 按定义即为拼配茶，旨在达到一致的风味特征                                            |
| 名丛   | 单一优质无性繁殖茶树，或单一品种——不包括肉桂和水仙                | 古老的命名茶；四大名丛为铁罗汉、水金龟、白鸡冠和半天妖 |
| 肉桂      | 肉桂品种，无性繁殖                                                        | 桂皮香，辛辣锐利                                                          |
| 水仙    | 福建水仙品种，无性繁殖                                                        | 大叶，醇厚顺滑，花香                                                            |
| 奇种     | 种子繁殖的*菜茶*——当地地方品种群体                                                        | 野生，多变，很少以单一名称出售                                                 |

注意排除项：肉桂和水仙占据主导地位，以至于标准将它们单独列为类别。

## 岩韵背后的地质学

武夷峡谷是丹霞地貌，切入晚白垩世基岩：红色砂岩和砾岩，其中混合有火山凝灰岩和流纹岩层。火山岩确实是混合物的一部分，但这并非夏威夷意义上的熔岩衍生土壤——它是风化的红层砾岩，这一差异对其排水性至关重要。

由此产生的土壤薄、多砾石、排水快：砾石含量约25%至29%，孔隙率接近50%，表土极少。茶树生长在岩石裂缝和常规农业不会涉足的斜坡上，根系向下伸入裂缝，而非向外扩展到田野。

这是否能产生独特的茶汤已被测试。2019年的一项研究在三个产区取样了112个茶园，采集了1,120份鲜叶样品和224份土壤样品，并通过质谱法进行分析。研究发现了1,058个代谢物信号，以约95%的准确率对原产地进行了分类，并计算出**原产地解释了代谢物总变异的32.9%**。正岩和周茶清晰分离；半岩介于两者之间。

最后一个数字值得记住。原产地是真实且可测量的——但它只占差异的大约三分之一。其余来自品种、加工和焙火。任何仅凭峡谷名称向你推销茶叶的人，都是以全价卖给你故事的三分之一。

## 正岩、半岩、周茶

三个区域，三个价格层级，且没有面向消费者的测试来区分它们。

表格

| 区域                 | 位置                                                                                        | 母质土壤                 | 杯中表现                                             |
| -------------------- | -------------------------------------------------------------------------------------------- | --------------------------- | ------------------------------------------------------ |
| 正岩（核心岩区） | 景区内——牛栏坑、慧苑坑、流香涧、悟源涧、九龙窠、竹窠 | 紫红色砂岩砾石 | 矿物感最重，余韵最长，最昂贵 |
| 半岩（半岩区）   | 峡谷与谷底之间                                                      | 红色硅铝质土壤   | 中等；通常性价比高                         |
| 周茶（洲茶） | 谷底和河岸                                                                  | 冲积沙               | 较淡，较薄，较便宜                              |

正岩和周茶之间的差距是中国茶中最常被滥用的说法。区域是由地理定义的，而非任何你可以对茶叶进行的测试，因此证书只能证明卖家所说，而非茶叶的生长地。根据口味购买，并选择你可以回头找的卖家。

## 大红袍是拼配茶

标准的定义明确无误：大红袍是由多个无性繁殖的武夷品种的半成品原料，经拼配匀堆制成。它是一种构造茶，旨在达到一致的感官目标，并且几十年来一直如此。

混淆来自母树——九龙窠悬崖上的六棵茶树，现已受保护且不再采摘。它们的扦插繁殖产生了业界所称的纯种大红袍，即从这六棵植株的无性后代种植而成。它确实存在，稀有且昂贵。

几乎所有作为大红袍出售的都是拼配产品。这不是丑闻；这就是定义。你应该关心的是原料的质量和焙火技艺。

一个标签说明：标准将大红袍分为三个等级——特级、一级、二级——并将特级描述为条索紧结壮实，香气锐长，汤色橙黄明亮。名丛则完全没有分级。

## 你实际会喝到的两种茶

业界有句老话：香不过肉桂，醇不过水仙。它们之间是武夷岩茶的主力茶，大多数大红袍拼配都以它们为基础。

肉桂是辛辣的那种。名字意为“桂皮”，香气确实辛辣——树皮、丁香，中国人称之为“辛锐”的锐利感。

水仙是宽厚柔和的那种：大叶品种，成熟晚，茶汤更圆润、更醇厚，刺激性较小。老丛水仙，来自几十年树龄的茶树，增添了木质、苔藓般的深度，这是年轻茶树所没有的。

## 制作：发酵，然后焙火

采摘在四月下旬谷雨节气前后进行，采用*开面采*：等待新梢成熟、叶片展开，然后采两到四叶。过早采摘会使叶片太嫩，无法承受随后的摇青。

摇青是决定性的步骤。*做青*是在滚筒中摇动叶片与静置交替进行，反复多次，持续数小时。叶片边缘的损伤启动发酵，而中心保持绿色，产生经典描述：绿叶红镶边。加热杀青在此停止发酵，然后揉捻和干燥。

接下来是岩茶在乌龙茶家族中的定义性步骤：木炭焙火，在数周内进行多轮，每轮之间让茶叶静置。焙火程度是一种风格选择，对茶叶的改变超出大多数买家的预期。

表格

| 焙火程度 | 中文    | 特点                                                      |
| ----------- | ---------- | -------------------------------------------------------------- |
| 轻       | 清香 | 绿色和花香，最接近未焙火的茶叶；褪色最快 |
| 中      | 中火  | 焙火与花香的平衡；最安全的起点         |
| 重       | 足火     | 深色，深沉，低香，余味悠长甘甜；保存最久        |

几乎没人提到的一个后果：刚焙火的岩茶有火味。需要数周至数月的静置，让焙火融入，过早饮用是人们决定不喜欢这个类别的最常见原因之一。如果你直接购买，询问焙火时间。

## 冲泡

岩茶需要沸水、小容器和短时间冲泡。茶叶紧结且重焙火，因此需要热量来展开，但它很快释放风味。

表格

| 参数        | 建议                                |
| ---------------- | --------------------------------------------- |
| 茶叶             | 7–8克                                         |
| 茶具           | 110–120毫升瓷盖碗或小陶壶 |
| 水温            | 100°C                                        |
| 洗茶            | 快速洗一次，弃去，以唤醒茶叶  |
| 第一泡   | 10秒                                    |
| 第二、三泡 | 15秒                                    |
| 之后每泡   | 增加5–10秒                              |

在学习茶叶时，瓷器是更好的选择，因为它告诉你茶叶的状态；陶壶会随着使用而养出茶味，并开始美化你放入的一切。一般原则请参阅我们的[乌龙茶指南](<>)和[水温指南](<>)。

## 购买与储存

焙火程度应该是你的第一个决定，而不是著名的名字。轻焙火肉桂和重焙火水仙之间的差异，比不同价格的两款大红袍拼配之间的差异更大。

储存与大多数人的假设相反。轻焙火岩茶是脆弱的那种——花香前调在一年内消失，茶变得平淡。重焙火可保存两到三年，并且通常在最初一年随着火气消退而改善。保持密封、避光、干燥，不要放冰箱。我们的[茶叶储存指南](<>)涵盖了通用规则。

## 常见问题

### 大红袍和武夷岩茶一样吗？

不。武夷岩茶是类别；大红袍是其中五种产品类型之一，法律上是多个品种的拼配。

### 岩韵实际上尝起来是什么味道？

它更多表现为质地而非风味：中段矿物感重量，茶汤感觉比看起来更厚，余韵不断回归。描述会用到湿石头。它不是烟熏味，也不等同于焙火。

### 武夷岩茶含有多少咖啡因？

每杯约30至50毫克，与红茶相似。焙火不会去除咖啡因，因此重焙火茶不是低咖啡因茶。我们的[按茶类划分的咖啡因含量](<>)有完整比较。

### 岩茶会过期吗？

它会衰退而非变质。轻焙火茶最好在一年内饮用；重焙火茶可保存两到三年，并在最初一段时间内稳定。正确储存不会让你生病，只是会变得不再有趣。

## 关键要点

* 武夷岩茶是五种法定定义的乌龙茶类型，而非一种茶——大红袍、名丛、肉桂、水仙和奇种。
* 大红袍法律上是多个无性品种的拼配；九龙窠的六棵母树受保护且不再采摘。
* 峡谷是丹霞地貌，由白垩纪红色砂岩和砾岩混合火山岩层构成——薄、多砾石的土壤迫使根系伸入裂缝。
* 原产地可测量但非决定性：2019年对112个茶园的研究发现，区域解释了32.9%的代谢物变异。品种和焙火占其余部分。
* 在110毫升容器中冲泡7–8克，用沸水，第一泡十秒。如果尝起来有火味，说明焙火太近——让它静置。
