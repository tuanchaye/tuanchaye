茉莉花茶是吸收了新鲜茉莉花香的绿茶。将花朵铺在成品茶上，静置一夜，然后移除花朵；茶叶经过干燥，再用新一批花朵重复此过程。它不是添加了茉莉香精的茶，而且——这会让大多数人感到惊讶——制作精良的茉莉花茶几乎不含任何花朵。

你购买的是茶叶与花朵共度的夜晚数。这个数字，以及底层茶叶的品质，是8美元一罐和60美元一罐的区别所在。

## 窨制，而非添加香精

茶底是成品绿茶，通常是福建的烘青绿茶，春季采摘并储存至夏季。所用花朵为*茉莉*（*Jasminum sambac*）。花蕾在下午采摘时尚未开放，然后保持低温直到傍晚，因为茉莉在夜间开放并释放香气。整个生产日程都按照花朵的生物钟运行，而非制茶者的时间表。

一旦花蕾开放，便将茶叶与花朵层层铺叠，静置10至12小时。花堆因花朵呼吸而升温，因此必须翻动散热——这一步骤称为*通花*——然后再收拢。到早晨，花朵已释放出全部香气，并在约三小时内被筛除。茶叶经过轻柔复烘，以驱除随香气一起吸收的水分，然后第二天晚上用新鲜花朵重新开始整个过程。

一轮称为一个*窨*。整个过程绝不快速：顶级茉莉花茶在装箱前可能需要六个月和一百多道独立处理工序。

## 决定价格的数字

中国茉莉花茶加工国家标准GB/T 34779-2017规定了每个等级应接受的窨制轮数和鲜花用量。差距巨大。

表格

| 等级                         | 窨制轮数                                    | 每100公斤茶叶的鲜花用量 |
| ----------------------------- | -------------------------------------------------- | ------------------------------- |
| 大白毫（大银针） | 六次，外加一次提花轮                        | 270公斤                          |
| 银毫          | 六次，外加一次提花轮                        | 200公斤                          |
| 特级                 | 四次，外加一次提花轮                       | 120公斤                          |
| 三级                       | 一次压花轮，一次鲜花轮，外加提花 | 50公斤                           |
| 五级                       | 一次压花轮，一次鲜花轮，外加提花 | 30公斤                           |

表中两个术语需要解释。**压花轮**重复使用已经释放大部分香气的花朵，将其压入茶叶中以提取剩余香气——这是一种节约措施，而非品质措施。**提花轮**（*提花*）是用少量最佳鲜花进行的最后一次轻窨，每100公斤茶叶约5至10公斤，不进行复烘，以保持头香明亮和挥发性。

在标准等级之上，福州制茶师将优质茶窨制多达七至九次，每晚使用一次新鲜花收获。当商家在罐上印着“九窨”时，这就是他们所声称的——而且你可以部分通过茶叶在第二和第三泡中的表现来验证这一说法。

## 为什么茶袋里没有花

因为它们被筛除了。花朵在茶叶到达你手中之前已完成工作；留在茶中只会增加水分，并随着时间产生陈旧、植物味。

干燥花瓣有时确实会出现在茶袋中，事后为外观而添加。少量散布无害。但依赖可见花朵来吸引人的茶，通常是普通茶底加上装饰性点缀，第二泡时香气就会消失。

对常见说法的一个纠正：你会读到高级茉莉花茶必须只闻起来有茉莉花香，没有其他花朵的痕迹。实际上，国家标准明确允许少量白兰（*白兰*）作为底花——每100公斤茶叶最多1.5公斤——以提升茉莉花香。淡淡的白兰底韵是正常的工艺，而非掺假。你应该反对的是闻起来像白兰*而非*茉莉的茶。

## 窨制 vs. “茉莉香精”

成分表比任何品鉴笔记都能更快地说明问题。“绿茶，茉莉花”意味着茶叶经过窨制。“绿茶，天然茉莉香精”或“茉莉香精”意味着施加了香气，照片中再多的花朵也无法改变这一点。

冲泡测试比标签更可靠。加香茶在干茶中大声宣告自己，然后崩溃：第一杯香气扑鼻，第二杯则是淡薄的普通绿茶。正确窨制的茶通常在第二泡时*更好*，一旦表面香气稳定，茶本身的甜味便显现出来。

## 它实际尝起来如何

从花朵转移到茶叶的香气化合物已被充分表征：邻氨基苯甲酸甲酯、乙酸苄酯、芳樟醇、吲哚、苯甲酸甲酯和水杨酸甲酯。它们共同产生人们联想到这种茶的葡萄般、金银花和清凉花香调。

品种比大多数买家意识到的更重要。一项2025年的代谢组学研究比较了‘圆叶’品种与传统重瓣类型在连续窨制轮次中的表现，发现圆叶更优雅清新，重瓣更饱满柔和。研究还发现圆叶的香气在第四轮左右更早饱和，而重瓣则持续改善至第五轮。超过那个点，更多的花朵对于那种特定茶叶不再能换来更多香气。

关于你可能看到的引用数字，需要提醒一句。一项2023年的代谢组学研究确实在窨制茶中鉴定出585种化合物，而花朵中有589种，其中70种仅在窨制后出现在茶中。这些是**非挥发性**化合物——负责味道和口感，而非气味。它们与香气无关，将其作为香气发现来引用是一个常见错误。

## 冲泡方法

福建省茉莉花茶冲泡与品鉴标准（DB35/T 1634-2016）给出了具体参数，在器皿尺寸和比例方面值得遵循。

表格

| 参数          | 直接饮用（盖碗或玻璃杯）  | 共享，倒入公道杯 |
| ------------------ | ---------------------------------- | ----------------------------- |
| 器皿             | 150毫升盖碗，或150–200毫升玻璃杯 | 200–250毫升壶或盖碗      |
| 茶水比 | 1:50至1:70                       | 1:30至1:50                  |
| 水温  | 90–100 °C                          | 90–100 °C                     |

标准还指出，对于高级特色茉莉花茶使用稍凉的水，对于标准等级使用更热的水——这是合理的，因为茶底不同。娇嫩的芽茶会被烫伤；粗老的等级茶需要热量才能展开。

冲泡时间短且累加：

表格

| 泡数       | 时间             |
| -------------- | ---------------- |
| 第一泡          | 15–30秒    |
| 第二泡         | 20–40秒    |
| 第三泡          | 25–45秒    |
| 之后每泡 | 增加5–10秒 |

标准中有一点可以忽略：它还规定品鉴室应保持在15–27°C，湿度不高于70%。那是专业评判的感官评估环境，而非你厨房的要求。没有人需要为水壶控制气候。

如果你习惯西式绿茶冲泡，或者你的茉莉花茶是细嫩芽茶，从80–85°C开始，然后逐步提高。福州使用的烘青茶底能承受接近沸腾的水，但较凉的水是更安全的首次尝试。关于此的通用版本，请参阅我们的[水温指南](<>)和[茶水比指南](<>)。

## 储存方法

茉莉花茶与普洱茶相反。它不会随着陈化而改善；香气化合物是挥发性的，它们会离开。保持密封、阴凉、避光，并远离任何气味浓烈的东西——茶叶会吸收橱柜里的任何气味，而这正是其制作过程的全部意义。在一年内饮用。到十八个月时，即使好茶也会变得平淡。

除非罐子是真空密封的，否则不要放入冰箱。每次打开时，冷茶遇到暖空气并凝结水珠，而湿气是另一个毁掉它的因素。

## 常见问题

### 茉莉花茶总是绿茶吗？

不是。茉莉描述的是窨制工艺，而非茶类。绿茶是经典且最常见的茶底，但白茶（茉莉银针）和红茶茶底都存在且值得一试——同样的花朵搭配更柔和或更麦芽香的茶叶。

### 茉莉花茶含有咖啡因吗？

是的，大致与其制作所用的茶叶相同——绿茶茶底通常每杯30至50毫克，白茶茶底更少。花朵不增加咖啡因。我们的[按茶类划分的咖啡因含量](<>)分解有完整范围。

### 为什么我的茉莉花茶尝起来苦？

水太热，或冲泡时间过长。苦味来自过度萃取茶叶，而窨制绿茶比看起来更脆弱。在缩短冲泡时间之前，将水温降低约10°C——你想保留花香头调，而热量会首先破坏它们。

### 茉莉花茶对健康有益吗？

茶底是绿茶，因此它含有与单独饮用该绿茶相同的儿茶素和咖啡因。茉莉贡献的是香气，而非有意义的营养。有关于茉莉花茶与情绪的动物研究，但尚未在对照人体试验中显示，因此将其视为一种令人愉悦的饮品而非药物。这是一般信息，而非医疗建议。

## 关键要点

* 茉莉花茶是用新鲜*茉莉*花经过反复过夜窨制而成的绿茶——而非添加香精的茶。
* 每轮窨制后花朵被筛除。好的茉莉花茶几乎不含花，可见花瓣通常是装饰。
* 窨制轮数决定价格：中国GB/T 34779-2017规定，五级每100公斤茶叶用30公斤鲜花，顶级用270公斤。
* 成分表上的“天然茉莉香精”意味着喷洒，而非窨制。窨制茶在第二泡时改善；加香茶则崩溃。
* 在150毫升器皿中以1:50的比例冲泡，第一泡15–30秒，如果茶变苦，将水温降至80–85°C。
