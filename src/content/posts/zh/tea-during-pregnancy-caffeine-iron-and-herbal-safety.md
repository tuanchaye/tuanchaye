简短的答案是数字：**每天200毫克咖啡因**。这是英国国家医疗服务体系（NHS）、美国妇产科医师学会（ACOG）和欧洲食品安全局使用的上限——大约两三马克杯的普通茶。

但咖啡因只是大家谈论的部分。还有三件事同样重要却鲜少被提及：随餐饮茶会阻碍植物性食物中部分铁的吸收；甘草根应完全避免，而不仅仅是限制；孕晚期最常被推荐的草本茶，其证据虽令人安心却较为薄弱。

## 关键数字：每天200毫克

NHS建议孕妇咖啡因摄入不超过每天200毫克，并指出持续超标与流产和死产风险增加有关。ACOG更谨慎地设定了相同阈值：每日低于200毫克的中等摄入量“似乎不是流产或早产的主要诱因”——同时补充说，与胎儿生长受限的关系“尚未确定”。

最后一点很重要。200毫克这个数字是未证实有害的水平，而非已证明安全的水平。

一杯茶实际含多少咖啡因（[按茶类的完整分解](<>)）：

| 饮品（8盎司/237毫升） | 咖啡因 |
| ---------------------- | -------- |
| 红茶，冲泡 | ~47毫克 |
| 乌龙茶，冲泡 | ~38毫克 |
| 绿茶，冲泡 | ~28毫克 |
| 白茶，冲泡 | 14–61毫克 |
| 抹茶，2克份量 | 38–88毫克 |
| 低因红茶 | ~2毫克 |
| 草本浸泡茶 | 0毫克 |
| 滴滤咖啡，供对比 | ~95毫克 |

![](/images/mirrored/ded86e20f514937b.jpg)

**马克杯陷阱。** NHS将一杯茶定为约75毫克；美国农业部（USDA）8盎司的数据为47毫克。两者都对：英式马克杯容量接近350毫升且通常冲泡较浓，美式杯为237毫升。如果你用大马克杯喝，请按两杯计算——这是女性最常超过200毫克的方式。

**第二泡。** 大部分咖啡因在第一次冲泡时已从茶叶中释出。再次冲泡同样的茶叶，咖啡因含量约为一半，第三泡再减半。如果你更想要仪式感而非提神效果，复泡是最简单的控制手段。

**剩余额度。** 茶很少是唯一的咖啡因来源。根据NHS数据，一罐可乐约40毫克，50克黑巧克力低于25毫克，一杯滤泡咖啡约140毫克——两杯咖啡就会让你在喝茶之前就超标。瓜拉纳和某些“能量”补充剂是伪装的咖啡因。

## 茶与铁：比咖啡因计算更重要的规则

茶的多元酚——带来苦涩味的化合物——会结合非血红素铁，即植物、豆类、扁豆和强化谷物中的铁形式。随富含铁的餐食饮用浓茶，会降低铁的吸收。

在孕期这并非小事。血容量增加约40%至50%，铁需求随之上升；缺铁性贫血是孕期最常见的并发症之一。每餐都喝茶的习惯会以任何咖啡因图表都无法显示的方式对你不利。

解决办法是调整时间，而非戒茶。在喝茶与富含铁的餐食或产前补充剂之间留出一小时。如果你确实随餐饮茶，请在同一餐中加入维生素C来源——柑橘、辣椒、番茄——以抵消抑制作用。服用铁剂时用水或果汁送服，绝不要用茶。

## 绿茶、叶酸与一项试管发现

搜索“绿茶 孕期”，你会看到警告：绿茶的主要儿茶素EGCG会抑制二氢叶酸还原酶——一种回收叶酸的酶。这一发现是真实的，但来自体外研究。

培养皿中的酶抑制不等于喝两杯茶的人会缺乏叶酸。没有研究表明普通绿茶会导致神经管缺陷，一项脊柱裂病例对照分析发现总体上与茶无关联，尽管它提示较高摄入量可能存在交互作用。

实际结论平淡无奇：保持绿茶适量，并按医嘱服用叶酸补充剂。这是唯一有强证据支持神经管保护的补充剂，不应依赖饮料来提供。

## 草本茶并非自动安全

“草本”意味着“非来自*Camellia sinensis*”——[这一区别值得了解](<>)。它并不意味着“在孕期经过研究”。浸泡茶中的大多数草本从未在孕妇中测试过，这就是为什么NHS将草本茶限制在每天四杯，并建议避免任何含甘草根的产品。

![](/images/mirrored/bc2aa9932f292aac.jpg)

甘草是明确的禁忌。甘草根含有甘草酸，高摄入量与婴儿发育受损有关——因此NHS将甘草根茶列为应避免的饮品，而非限制。正常量的甘草糖没问题；甘草*根*茶则不行。

除此之外，避免清单基于药理学而非民间传说：

* **泻药和“排毒”茶**——番泻叶、鼠李皮，以及任何标榜减肥或清洁的产品。这些确实可能造成伤害，且很少作为孕期产品营销。
* **除蚤薄荷、聚合草、款冬**——有文献记载毒性的传统草药。
* **大量鼠尾草**——作为调味料可以，但不宜每日冲泡饮用。
* **蒲公英和荨麻**——利尿剂，在液体需求增加时适得其反。
* **多草本“孕期茶”混合包**——一袋八种草本意味着八个未知数，且无法归因于某种效果。

两种草本在正常量下通常可以接受：**生姜**缓解恶心，**薄荷**缓解烧心——不过薄荷会松弛食管括约肌，对某些女性会加重反流。洋甘菊适量同样没问题。

## 覆盆子叶：证据究竟怎么说

这是你会被建议购买的草本，所以值得一个直接的回答。

英国约四分之一的孕妇和澳大利亚超过三分之一的孕妇使用覆盆子叶，几乎总是相信它能强健子宫并缩短产程。**没有随机试验表明它能缩短产程**——综述的结论就在于此。

关于安全性，人体数据令人安心但薄弱。一项回顾性队列研究（57名使用者与51名对照）未发现不良反应，一项安慰剂对照试验（192名初产妇从32周起每日服用2.4克提取物）也未发现，除了四名女性可能出现便秘。英国毒性委员会于2024年审查了所有数据，结论是风险**低，但不确定性高**，因为数据非常有限。欧洲药品管理局在2013年更进一步：由于缺乏有效性和安全性证据，不建议在孕期使用覆盆子叶。

两点注意事项。英国的消费量估计高达该试验剂量的四倍，因此“2.4克无不良反应”并不涵盖每天六杯浓茶。此外，有一例已发表的病例：一名使用胰岛素的妊娠期糖尿病女性在饮用覆盆子叶茶后出现低血糖——如果你属于这种情况，请避免使用。

如果你仍要使用：告诉你的助产士，不要在孕晚期之前开始，不要泡得比普通茶更浓，也不要期望任何可测量的效果。

## 如果你已经喝了很多

大多数在检测阳性前喝惯常茶的女性会担心这一点，答案通常令人安心：伤害证据在高摄入量时最强，且关注的是整个孕期的概率，而非任何一杯茶。值得做的是适度的——计算一两天你的咖啡因摄入量，将部分茶换成低因茶或第二泡，让茶远离餐食和补充剂，并在下次就诊时提及。

## 常见问题

### 我每天可以喝多少杯茶？

按NHS每马克杯约75毫克计算，两到三马克杯可保持在200毫克以下。按USDA每8盎司杯47毫克计算，四杯仍可——如果你一天中没有其他含咖啡因的东西。

### 孕期喝低因茶安全吗？

安全。[低因红茶](<>)每杯约含2毫克，可忽略不计。它仍含有多元酚会抑制铁吸收，因此时间规则仍然适用。

### 我可以用茶送服产前维生素吗？

不可以。间隔约一小时。茶多元酚会降低补充剂中铁的吸收，而产前铁是孕期少数吸收真正重要的东西之一。

### 洋甘菊茶安全吗？

通常安全，适量饮用，在NHS的四杯草本上限内。如果你对豚草或菊科植物过敏，请避免——交叉反应已有充分描述。

## 关键要点

* **每天200毫克咖啡因**是NHS、ACOG和EFSA的限值——大约两到三马克杯，大马克杯或咖啡则更少。
* **第二泡的咖啡因约为第一泡的一半**：这是不戒茶习惯而减少摄入的最简单方法。
* **随餐饮茶会降低铁吸收。** 在富含铁的食物或产前补充剂前留出一小时。
* **甘草根是明确的禁忌**；泻药和“排毒”茶是真正可能造成伤害的产品。
* **覆盆子叶广泛使用但未经证实**：英国2024年审查发现风险低但不确定性高，EMA不建议使用。
