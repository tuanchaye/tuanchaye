你的这杯茶按重量计约98%是水。你能品尝到的一切——甜度、涩感、香气——都来自另外那2%。水不是中性的载体，而是一种活性成分，其化学性质决定了那2%中有多少能到达你口中。

有三个测量指标很重要：总溶解固体（TDS）、硬度和碱度。第四个指标pH值之所以重要，主要是因为它随前三个指标一起变化。把这些指标大致调对，普通的茶会好喝得出乎意料；调得严重不对，再好的茶也寡淡无味。

简而言之：目标是中等偏软的水，接近中性，碱度低。但这个建议背后存在一种真实的矛盾，它解释了为什么两位同样用“正确”的水、同样细心的品饮者，会对什么是好水产生分歧。

## 三个关键数值

这些不是同一种测量，把它们混为一谈是这里最常见的错误。

表格

| 测量指标    | 它实际是什么                                                           | 它对茶的影响                                                                                         |
| -------------- | ----------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **TDS**        | 所有溶解物质——矿物质、盐类、有机物——以百万分率计 | 首要数值。太低：茶汤淡薄空洞。太高：沉闷、粉感、香气被压抑                          |
| **硬度**   | 特指钙和镁，以碳酸钙当量表示  | 执行萃取工作的离子。太低：萃取不足。太高：结合多酚，增加涩感 |
| **碱度** | 缓冲能力，主要是溶解的碳酸氢盐                              | 对萃取毫无帮助。中和让茶尝起来明亮的酸类                           |
| **pH**   | 0–14刻度上的酸度                                                       | 实践中随碱度变化。低于6.5有酸味风险；高于7.5使茶汤平淡                        |

硬度和碱度经常被混淆，但它们不是同一回事。硬度是矿物质对茶叶起作用；碱度是缓冲剂，会吃掉茶汤中的酸度。水可能显示合理的硬度，却仍含有足够的碳酸氢盐，把你泡的每一杯茶都变得平淡。

## 茶叶研究实际发现了什么

中国农业科学院茶叶研究所的研究人员用四种水——纯净水、山泉水、矿泉水和天然水——以1:50的茶水比冲泡清香型和浓香型[铁观音乌龙茶](<>)六分钟，然后对茶汤评分并分析挥发性成分。

表格

| 水类型      | 矿化度 | 评审小组的发现                                                              |
| --------------- | -------------- | --------------------------------------------------------------------------------- |
| 矿泉水   | 高           | 总分最低。滋味平淡，香气浑浊，风味化合物浸出差 |
| 天然水   | 中等       | 四种水中总挥发性化合物最高                                      |
| 山泉水 | 中等       | 两种乌龙茶的总可接受度最高                               |
| 纯净水  | 接近零       | 四种水中总挥发性化合物最低                                       |

注意这个结果的形态。纯净水在香气上排在**最后**，而不是第一。零矿物质不是目标——它是两种失败模式之一。

2025年《食品科学》的另一项研究用14种水测试生普洱，pH值从6.56到8.53，TDS从8到120 mg/L。高TDS水增加了感知的醇厚度，但过量的钙和镁抑制了多酚萃取。接近中性的水（pH 6.5–7.5）释放了更多氨基酸和更多香气。得分最高的汤色来自钙和镁低于5 mg/L的水，而香气得分最高的是碳酸氢盐低于80 mg/L的水。

两项研究对于“多软才算太软”并不完全一致：乌龙茶研究发现中等矿化度在香气上优于纯净水，而普洱研究则偏好极低的钙和镁。但它们在方向上一致——矿物质越多意味着醇厚度越高、香气越少；矿物质越少意味着更干净、更明亮、更淡薄的茶汤。在两者之间取什么位置，取决于口味和你泡什么茶。

## 硬水为何使茶平淡

高钙会产生一种奇特的效果：它降低苦味、鲜爽度和甜度，同时*提高*涩感。结果是茶汤既平淡又粗糙——没有甜度来圆润边缘，但舌面上有一种迟来的、持久的干燥紧涩感。它还抑制携带香气的挥发性化合物，这就是为什么高矿化度的水会产生乌龙茶研究中所说的浑浊香气：气味还在，但混乱不清，仿佛隔墙听声。

![](https://s.coze.cn/image/WCdSWNWbM4s/)

这里的权衡变得具体了。最大化香气的同一种低矿物质水也会萃取出更多儿茶素——即苦味和涩感背后的化合物。软水给你更明亮、更芬芳，但也更苦、更涩的茶汤。硬水则相反：更圆润、更厚重、更沉闷。两者在抽象意义上没有优劣；它们是同一片叶子泡出的不同饮品。

关于把儿茶素数值当作健康数值来解读，有一点需要注意：萃取到杯中的量不等于你身体吸收的量。萃取研究测量的是前者，无法回答后者。

## 没人告诉你的事：煮沸会改变你的水

那项普洱研究对全部14种水测量了两次——室温和煮沸后。每一种都发生了变化，而且方向相同。

* **全部14个样品的pH值都升高了**，升幅为6%到27%。所有样品最终都高于7.0。碱性最强的样品冷时pH已达8.53，煮沸后达到9.45。
* **TDS升高了4%到200%。**
* **电导率升高了6%到207%。**

原因很简单：水沸腾时溶解的二氧化碳作为气体逸出，带走了碳酸，因此pH值上升。更高的温度也会溶解更多盐类。你的水壶不是中性容器，而是反应容器。

两个实际后果。第一，冷时测量的水不是你泡茶用的水；从水龙头取的TDS读数低估了杯中的实际含量。第二，每次煮沸都会以蒸汽形式带走水，而把矿物质留下。整个上午不把水壶倒空而不断加水，每一轮开始的矿物质负荷都比上一轮更高——这通常就是茶随着一天过去越来越平淡的原因。

## 读懂你自己的水

你无法修正没有测量过的东西，而测量成本很低。

在美国，每个市政供水商都会在公用事业网站上免费发布年度消费者信心报告。查找硬度、碱度和使用的消毒剂；报告呈现这些信息的方式各不相同，所以要阅读脚注。

一支TDS笔大约花费十五到二十美元。它的局限性值得了解：它测量电导率并推断TDS，所以它告诉你溶解了多少，而不是溶解了什么。两种读数150 ppm的水可能表现完全不同，因为一种可能主要是碳酸氢盐，另一种主要是硫酸钙。把TDS笔当作标题，而不是诊断。

最广泛引用的数值参考来自美国精品咖啡协会：TDS 75–250 ppm，目标值150；硬度50–175 ppm（以碳酸钙计）；碱度40–70 ppm；pH 6.5–7.5。它是为咖啡而非茶制定的，茶叶研究倾向于更低的范围——但这是唯一广泛发布的标准。

## 调整水质

表格

| 问题                          | 尝起来如何                      | 解决方法                                                                            |
| -------------------------------- | ---------------------------------------- | ------------------------------------------------------------------------------ |
| 太硬（高TDS和高硬度） | 粉感、沉闷、香气被压抑                | 与蒸馏水或反渗透水混合                                  |
| 太软（TDS低于约50）  | 淡薄、空洞，有时有金属味         | 混入少量自来水，或使用有公布TDS的泉水     |
| 高碱度                  | 无论什么茶叶都平淡无生气 | 碳过滤器无法去除——你需要反渗透或稀释                      |
| 氯                         | 药味、游泳池般的边缘            | 任何基本的碳过滤器                                                        |
| 氯胺                       | 同样的问题，但更难去除            | 标准碳不够——寻找标有可处理氯胺的催化碳 |

稀释是最便宜的工具，也是人们最容易忘记的。如果你的自来水读数是300 ppm，而你想要接近100，就把两份自来水和一份蒸馏水混合。这是算术，不是化学。

水化学只是你在水壶边控制的两个变量之一；另一个是[水温](<>)，同样重要。

顺序比精确度更重要：先去除氯或氯胺，因为这是最常见的问题，也最容易解决；其次测量TDS，看看你是否处于不良区间；第三检查碱度，因为它会在其他一切看起来正常时悄悄使茶平淡；最后微调矿物质，这是大多数人最先使用的最小杠杆。

如果你的水已经在合理范围内，进一步调整是精细控制，而非转变：在良好区间内追求完美数值产生的差异，你们会争论而不是品尝出来。茶叶也是如此——没有哪种水质配置能拯救普通的茶，而[从值得品尝的清晰叶片开始](<>)比任何矿物质调整都更能改变你的茶汤。

## 常见问题

### 泡茶的最佳TDS是多少？

对大多数茶来说，50到150 ppm之间效果不错，但单看数值并不能告诉你成分。低于约50 ppm，离子太少，无法将风味化合物带入溶液，茶汤会变淡。高于约250 ppm，矿物质会与茶叶作对而不是协同。

### 硬水会毁掉茶吗？

不一定。单是硬度主要改变醇厚度——更多钙意味着更厚重、更圆润的茶汤。毁掉茶的是硬度加上高碱度，因为碳酸氢盐中和了赋予茶汤明亮感的酸。如果碱度低，水可以中等硬度而仍然泡出好茶。

### 我可以用蒸馏水泡茶吗？

不能直接使用。蒸馏水和反渗透水的TDS接近零，而乌龙茶研究发现纯净水在测试的四种水中产生的挥发性物质含量最低。茶汤干净但空洞。用蒸馏水稀释硬自来水，而不是单独作为泡茶水。

### 为什么同一款茶在朋友家味道不同？

几乎总是水的原因。不同的供水系统，矿物质负荷和碱度可能相差数倍。同一片叶子在80 ppm和320 ppm下冲泡，并不是同一种饮品——这也是为什么在商家柜台让你印象深刻的茶，在家里可能令人失望。

## 关键要点

* 茶按重量计约98%是水，所以其矿物质含量是活性成分，而不是中性载体。
* TDS、硬度和碱度是三种不同的测量。碱度是使茶平淡的那个，而标准碳过滤器无法去除它。
* 矿物质越多意味着醇厚度越高、香气越少；矿物质越少意味着更干净、更明亮、更苦的茶汤。没有唯一正确的数值，只有一个方向。
* 煮沸会同时提高pH值和TDS。反复煮沸半壶水，每一轮都会进一步浓缩它们。
* 先解决氯，再解决碱度，最后微调矿物质。大部分收益来自离开不良区间，而不是在良好区间内追求完美数值。
