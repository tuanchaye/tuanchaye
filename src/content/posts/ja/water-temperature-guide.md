おいしい茶葉を台無しにするものを茶飲み愛好家に尋ねると、必ずこう返ってきます。*お湯の温度が間違っている*。熱すぎると繊細な茶は焦げて苦くなり、冷たすぎると力強い茶は平坦な味になります。以下が実用的な早見表です。

## 種類別の温度
| 茶葉の種類 | 温度 | 備考 |
|---|---|---|
| 白茶 | 80〜90°C | 柔らかな芽。低めの方が安全 |
| 緑茶 | 75〜85°C | 85°Cを超えると苦くなる |
| 黄茶 | 80〜85°C | 穏やかな緑茶のようなもの |
| 烏龍茶（軽発酵） | 90〜95°C | |
| 烏龍茶（濃発酵・焙煎） | 95〜100°C | 高温を好む |
| 紅茶 | 90〜100°C | 力強く、沸騰湯でも可 |
| プーアル茶（生・熟） | 95〜100°C | 開かせるには熱が必要 |
| 抹茶 | 75〜80°C | 沸騰湯は絶対に不可 |

## 温度計がない場合
- **沸騰から30〜60秒** ≈ 90〜95°C（烏龍茶・紅茶に適す）。
- **沸騰から2〜3分** ≈ 80°C（緑茶・白茶に適す）。
- 最も繊細な芽にはさらに長く冷ましましょう。

## なぜ重要なのか
熱は甘みよりも早く苦味や渋味を引き出します。繊細な茶には優しい扱いが必要で、力強く丸められた茶や熟成茶は本物の熱がないとほぐれません。温度を茶葉に合わせれば、薄い味や苦い一杯はほぼなくなります。

この早見表をやかんのそばに置いておきましょう。茶葉の品質に次いで、抽出を最も大きく改善するポイントです。
